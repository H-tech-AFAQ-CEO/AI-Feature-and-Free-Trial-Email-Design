## Overview

SP360 is a comprehensive operational platform for DFCS (Division of Family and Children Services) providers. This page serves as both an email campaign and a landing page — announcing the FY27 contract offer and showcasing the platform's AI capabilities.

---

## Features

### Visual & Interactive Highlights

| Feature | Description |
|---------|-------------|
| **Hero Animation** | Staggered fade-in animations on headline, subtext, and CTA |
| **AI Graphic Flow** | Custom SVG flow diagram showing referral → AI → payment process |
| **Shimmer Effect** | Animated gradient overlay on the free offer card |
| **Scroll Reveal** | Elements fade in as they enter the viewport |
| **Countdown Timer** | Dynamic counter showing time remaining until July 1, 2026 |
| **Number Count-Up** | Statistics animate upward when scrolled into view |

### Page Sections

| Section | Content |
|---------|---------|
| **Top Bar** | Provider communication notice with external links |
| **Header** | Logo + "Free Until July 1" badge |
| **Hero** | Headline, AI flow graphic, dual CTA buttons |
| **Free Banner** | Prominent announcement of free access period |
| **Stats Row** | Key metrics (30s invoice batch, 3-click payroll, 100% free) |
| **AI Features** | 4 cards detailing referral AI, payment AI, invoice batching, payroll |
| **Screenshots** | 3 dashboard mockups with browser chrome simulation |
| **Core Features** | 4 feature items with numbered badges |
| **Jeannette AI** | Dedicated section introducing the AI colleague |
| **How We're Different** | 4 value propositions (no contracts, flat pricing, etc.) |
| **Pricing Card** | Free now → $495/month after July 1 |
| **Final CTA** | Centered call-to-action with guarantee badges |
| **Footer** | Brand info, legal links, unsubscribe notice |

### AI Capabilities Shown

- Referral/SA document upload — AI reads and auto-populates
- Payment document reconciliation
- Invoice batching (30 seconds per county)
- Payroll in 3 clicks
- Credential expiration alerts
- Note submission deadline tracking

- **HTML5** — Semantic email/landing page structure

- **Google Fonts** — Cormorant Garamond, DM Sans, Space Grotesk
- **Vanilla JavaScript** — Scroll reveal, countdown timer, number counters
- **SVG Icons** — Custom inline SVG graphics
- **Animate.css** — (Referenced but minimal custom animations used)
